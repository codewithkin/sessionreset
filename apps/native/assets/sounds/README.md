# Sound Files

Add the following sound files to this directory:

- `chime.wav` — Default notification sound
- `radar.wav` — Alternative notification sound
- `subtle-ping.wav` — Subtle notification sound

Requirements:
- Format: WAV (PCM)
- Duration: 1-3 seconds recommended
- Sample rate: 44100 Hz
- Bit depth: 16-bit

These files are played when local notifications fire (reset alerts and pre-reset alerts).
